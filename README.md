# ancient-greek-ai-model-tester
## DEMO:
[**GITHUB PAGE**](https://vmuggittu.github.io/ancient-greek-ai-model-tester/test-grc-ai-model.html)


Meant to test the full morphological analysis features ([XPOS Perseus standard](https://github.com/PerseusDL/treebank_data/tree/master/AGDT2/guidelines)) of Ancient Greek language available to ONNX AI models. Built upon [GreBERTa](https://huggingface.co/bowphs/GreBerta) and [Tranformers.js](https://huggingface.co/docs/transformers.js/en/index).  
Full details in paper below.
